# Project 06: Search Listing Ranking (Daily Rentals)

## Задача
Ранжирование объявлений посуточной аренды жилья в поисковой выдаче с учетом position bias (склонности пользователей кликать на первые позиции).

## Архитектура
- **Модель**: LightGBM LambdaRank (`LGBMRanker`).
- **Учет Position Bias**: Взвешивание обучающих примеров через Inverse Propensity Scoring (IPS-веса = `1 / P(Examined | pos)`).
- **Разбиение**: Групповое разбиение по `query_id` без утечки данных между обучающей и тестовой выборками.

## Целевые метрики
- Относительный прирост NDCG@10 модели над бейзлайном (сортировка по рейтингу) ≥ 10%.

## Как запустить
```bash
pytest -q tests/test_06_ranking.py
```

## Принятые компромиссы
- Модель склонности просмотра (propensity model) задана степенной функцией от позиции выдачи.
