# Project 03: RAG Support Bot

## Задача
Чат-бот технической поддержки на базе RAG (Retrieval-Augmented Generation) с автоматической эскалацией сложных и внеконтекстных вопросов на оператора.

## Архитектура
- **Векторное хранилище**: Qdrant в режиме `:memory:`.
- **Эмбеддинги & Retrieval**: TF-IDF символьные n-граммы с косинусным сходством.
- **Генерация**: `LLMClient` с добавлением атрибуции источников (`[doc_id]`).
- **Эскалация**: Если max similarity score < 0.25, диалог автоматически переводится на оператора.

## Целевые метрики
- Recall@5 по ретривалу знаний ≥ 0.85.
- Корректная эскалация 100% внеконтекстных вопросов.
- Расчет метрики Deflection Rate (доля закрытых обращений без участия оператора).

## Как запустить
```bash
pytest -q tests/test_03_rag_bot.py
```

## Принятые компромиссы
- Векторный индекс Qdrant запускается локально в оперативной памяти без внешних сетевых сервисов.
