# Project 02: Cold Call Analysis

## Задача
Анализ транскрипций холодных звонков менеджеров продаж: ASR транскрибация -> детекция возражений клиента (дорого, нет времени, уже есть провайдер, подумаю, нет потребности) -> генерация контекстной подсказки из скрипта.

## Архитектура
- **ASR**: Интерфейс `ASRInterface` с легким `TextStubASR` для стандартных быстрых тестов и `FasterWhisperASR` (faster-whisper) в тесте `@pytest.mark.slow`.
- **Классификатор возражений**: TF-IDF + Logistic Regression.
- **Подсказки**: Динамическое сопоставление возражения с шаблонами ответов скрипта продаж.

## Целевые метрики
- Macro F1 классификации возражений ≥ 0.80 на синтетических обращениях.
- 100% покрытие возражений валидными релевантными подсказками.

## Как запустить
```bash
pytest -q tests/test_02_call_analysis.py
```

## Принятые компромиссы
- Использование текстовой заглушки в быстрой тестовой батарее позволяет уложиться в лимит времени без скачивания весов Whisper.
