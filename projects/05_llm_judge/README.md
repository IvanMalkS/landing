# Project 05: LLM-as-a-Judge Dialogue Evaluator

## Задача
Автоматическая оценка качества диалогов поддержки с использованием модели-судьи (`LLMClient`), валидация относительно экспертной разметки и предотвращение деградации качества диалогов через CI-гейт.

## Архитектура
- **Оценка**: Вызов `LLMClient` для присвоения оценки 1-5 и текстового обоснования.
- **Метрики согласия**: Вычисление точности (Accuracy), матрицы ошибок (Confusion Matrix) и каппы Коэна (Cohen's Kappa).
- **CI Gate**: Автоматический скрипт валидации порога качества перед деплоем новой версии бота.

## Целевые метрики
- Кастомная реализация каппы Коэна совпадает с `sklearn.metrics.cohen_kappa_score`.
- CI-гейт блокирует сборку (exit code 1) при проседании каппы/точности и пропускает качественные релизы (exit code 0).

## Как запустить
```bash
pytest -q tests/test_05_llm_judge.py
```

## Принятые компромиссы
- Диалоги синтезированы с размеченными оценками качества 1-5 для воспроизводимой проверки метрик каппы Коэна.
