# Project 08: Similar Items Recommendation & Cold Start Handling

## Задача
Рекомендация похожих объявлений аренды жилья: матричная факторизация для теплых объектов с историей взаимодействий + контентные TF-IDF эмбеддинги для новых (холодных) объектов без истории.

## Архитектура
- **Collaborative Filtering**: Модель implicit ALS (Alternating Least Squares).
- **Cold-Start Recommender**: Контентные векторные представления на основе текстов описаний и характеристик объектов с косинусным сходством.

## Целевые метрики
- Доля похожих объектов из того же тематического кластера/категории ≥ 70%.
- Новые объекты без истории получают непустую выдачу с высоких уровнем релевантности.

## Как запустить
```bash
pytest -q tests/test_08_similar_items_coldstart.py
```

## Принятые компромиссы
- Использование TF-IDF текстовых эмбеддингов вместо тяжелых трансформеров для обеспечения высочайшей скорости на CPU.
