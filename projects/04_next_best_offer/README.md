# Project 04: Next Best Offer Recommendation & Drift Monitoring

## Задача
Персонализированная рекомендация топ-N тарифных опций и допуслуг абонентам телеком-оператора с еженедельным автоматическим переобучением и мониторингом дрейфа признаков.

## Архитектура
- **Модель**: CatBoostClassifier.
- **Оркестрация**: Airflow DAG (`nbo_retrain_weekly`) с еженедельным расписанием (`@weekly`).
- **Мониторинг**: Расчет Population Stability Index (PSI) для выявления сдвигов в распределении признаков.

## Целевые метрики
- Accuracy модели существенно выше случайного бейзлайна (> 0.50 vs 0.20).
- PSI < 0.10 на стабильных данных и PSI > 0.25 при наличии существенного дрейфа.

## Как запустить
```bash
pytest -q tests/test_04_next_best_offer.py
```

## Принятые компромиссы
- Синтетическая генерация профилей абонентов с детерминированными паттернами потребления трафика и минут.
