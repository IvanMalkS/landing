# Project 09: Search Query Parsing into Structured Filters (NER)

## Задача
Парсинг естественно-языковых поисковых запросов пользователя в структурированные JSON-фильтры (например, "у метро, с парковкой, до 3000" -> `{"near_metro": true, "parking": true, "price_max": 3000}`).

## Архитектура
- **Парсер**: Гибридный подход с использованием spaCy tokenization / regex rules matcher для точного извлечения числовых ограничений (цена, комнатность) и бинарных флагов (метро, парковка, балконы, питомцы).

## Целевые метрики
- Точность полного совпадения фильтров (exact match filter accuracy) ≥ 0.90 на 100+ тестовых запросах.
- Устойчивость к неизвестным словам и шуму.

## Как запустить
```bash
pytest -q tests/test_09_query_ner.py
```
