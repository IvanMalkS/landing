# Common Utilities Module

## Задача
Предоставление общего инструментария для всей платформы: A/B-тестирование, MDE, доверительные интервалы, симуляции A/A тестов и унифицированный интерфейс взаимодействия с LLM (`LLMClient`).

## Архитектура
- `ab_testing.py`:
  - Расчет абсолютного и относительного прироста (uplift).
  - Двухвыборочный Z-тест для пропорций с доверительными интервалами.
  - Расчет объема выборки по MDE (Minimum Detectable Effect) через `statsmodels.stats.power.NormalIndPower`.
  - `LLMClient`: Единая обертка над LLM с мок-реализацией для быстрых тестов и опциональным вызовом через переменные окружения.

## Метрики и верификация
- Тест A/A симуляций: 200 независимых запусков A/A теста. Порог ложноположительных срабатываний (FPR) <= 8% при alpha=0.05.

## Как запустить
```bash
pytest -q tests/test_common.py
```

## Принятые компромиссы
- Мок-режим `LLMClient` использует правила подстановки ключей для детерминированного воспроизведения ответов в CPU-тестах.
