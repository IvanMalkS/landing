# Project 07: Two-Tower Candidate Retrieval & Sequential Recommendation

## Задача
Двухстадийная рекомендательная система:
1. Candidate Retrieval: Two-Tower PyTorch модель с in-batch негативными примерами и векторным индексом FAISS.
2. Sequential Recommendation: Последовательная модель GRU4Rec-lite для учета истории кликов текущей сессии.

## Архитектура
- **Two-Tower**: Нейросетевые башни пользователя и объекта с L2-нормализацией эмбеддингов.
- **FAISS**: Векторный индекс `IndexFlatIP` для мгновенного поиска соседей.
- **GRU4Rec**: GRU-сеть для предсказания следующего интересующего объекта по сессионной последовательности.

## Целевые метрики
- Recall@50 Two-Tower модели превосходит популярный бейзлайн.
- HitRate@10 GRU4Rec модели превосходит непоследовательный бейзлайн.
- Результаты FAISS индекса полностью эквивалентны полному перебору (brute force) на небольшом индексе.

## Как запустить
```bash
pytest -q tests/test_07_two_tower_seq.py
```

## Принятые компромиссы
- Легковесная архитектура GRU обучена на CPU без использования тяжелых графических ускорителей.
